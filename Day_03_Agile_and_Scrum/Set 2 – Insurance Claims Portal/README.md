# Day 3 – Agile and Scrum Workshop (Set 2)
## Project: ClaimsPro Self-Service Insurance Claims Portal

### Overview
This repository and accompanying documentation contain the foundational Agile artifacts, product vision, Waterfall-versus-Agile comparison, prioritized product backlog, INVEST vertical splitting analysis, Gherkin acceptance criteria, Planning Poker sizing, Scrum framework summary, and Definition of Done (DoD) for **ClaimsPro** — a digital policyholder portal for lodging claims, uploading documents, and tracking settlement status.

### Summary of Workshop Tasks Completed

1. **Product Vision & Methodology Comparison:** Authored a product vision focused on rapid financial recovery and digital transparency, supported by a comparative analysis explaining why Agile fits an insurance portal better than Waterfall.
2. **Epics & User Stories:** Established 4 core epics (*Claim Registration*, *Document Upload*, *Claim Tracking*, *Settlement Notifications*) broken down into 13 user stories.
3. **INVEST Review & Vertical Slicing:** Conducted an INVEST evaluation, identifying oversized stories (e.g., `US-05`) and splitting them vertically into user-facing slices rather than horizontal technical layers.
4. **Acceptance Criteria:** Authored precise `Given / When / Then` acceptance criteria for claim registration stories, incorporating a negative validation failure scenario.
5. **Planning Poker & Backlog Estimation:** Estimated all 13 stories using Fibonacci values (`1, 2, 3, 5, 8, 13`), documented Planning Poker outlier discussions, prioritized via MoSCoW, and computed a total backlog size of **48 Story Points**.
6. **Jira Setup & Sprint Framework:** Configured a Jira Scrum project (`ClaimsPro Portal`), established workflow columns (`TO DO`, `IN PROGRESS`, `IN REVIEW`, `DONE`), and recorded the Definition of Done.
