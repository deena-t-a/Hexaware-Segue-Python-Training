# Day 3 – Agile and Scrum Workshop (Set 1)
## Project: FreshCart Online Grocery Application

### Overview
This repository and accompanying documentation contain the foundational Agile artifacts, Product Backlog, Scrum role definitions, user stories, INVEST evaluations, acceptance criteria, and Sprint planning outputs for **FreshCart** — a regional supermarket grocery ordering and home-delivery application.

### Summary of Workshop Tasks Completed

1. **Product Vision & Scrum Roles:** Established a clear product vision targeting urban/suburban grocery shoppers and defined the Product Owner, Scrum Master, and Developer roles along with real-world anti-patterns for each.
2. **Epics & User Stories:** Created 3 core epics (*Browse and Search*, *Cart and Checkout*, *Delivery Tracking*) broken down into 12 structured user stories in the `As a / I want / so that` format.
3. **INVEST Checklist & Refinement:** Evaluated all stories against the INVEST criteria, successfully splitting and rewriting oversized/ambiguous stories (`US-07` and `US-09`).
4. **Acceptance Criteria:** Authored precise `Given / When / Then` acceptance criteria for 5 key stories, including a negative scenario for promo code validation.
5. **Backlog Prioritization & Estimation:** Prioritized the backlog using **MoSCoW**, estimated stories using **Fibonacci sequence via Planning Poker**, and justified `US-01` (3 points) as the reference anchor story.
6. **Jira Setup & Sprint Planning:** Published all issues on a Jira Scrum board, organised them across **Sprint 1 (MVP)**, **Sprint 2**, and **Sprint 3**, and recorded the Definition of Ready (DoR) and Definition of Done (DoD).
