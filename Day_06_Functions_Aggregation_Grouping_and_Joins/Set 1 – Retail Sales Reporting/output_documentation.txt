Task 3 : NULL behaviour in COUNT(*), COUNT(column) and AVG
---------------------------------------------------------------------
Example 1 - COUNT(*) vs COUNT(column) on customers.phone

Result:

total_rows  rows_with_phone  null_phones
----------  ---------------  -----------
        10                7            3
(1 row)

COUNT(*) counts every row, so it returns 10. COUNT(phone) counts
only rows where phone is NOT NULL, so it returns 7. The
difference (3) is the number of customers with no phone number.

Example 2 - AVG on orders.discount_amount

Result:

total_orders  orders_with_discount  avg_ignoring_nulls  avg_nulls_as_zero
------------  --------------------  ------------------  -----------------
          18                     5              120.00              33.33
(1 row)

Only 5 of the 18 orders have a discount recorded, the rest hold NULL.
AVG ignores NULL values in both the sum and the count, so
AVG(discount_amount) = sum / 5 = 120.00.
If NULL is treated as 0 with ISNULL, the average is spread over all
18 orders and drops to 33.33. So the same column gives two different
averages depending on how NULL is handled. NULL means "unknown / not
given", not zero, and the choice must match the business question.
