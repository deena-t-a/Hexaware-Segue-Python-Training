# Retail Order Desk – Day 1 Training Module

## Overview
This repository contains solutions for Day 1 (Problem Solving Techniques and Data Structures – Set 1: Retail Order Desk). It covers foundational algorithm design, search/sort benchmarking, hash-based deduplication, custom data structures, and optimization paradigms (Greedy vs Dynamic Programming).

## File Structure
* `retail_order_desk.py`: Main source code containing implementations for all 5 tasks.
* `console_output.txt`: Captured console execution results (Deliverable 2).
* `complexity_note.md`: One-page complexity table and data-structure rationale (Deliverable 3).
* `README.md`: Project overview and documentation.
